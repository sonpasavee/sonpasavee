Hello! My name is Pasavee Pongkaew, a passionate Fullstack Developer specializing in React.js for frontend development and Spring Boot for backend services. I have hands-on experience in building modern, responsive, and scalable web applications, integrating intuitive user interfaces with robust backend APIs.

My technical expertise includes React.js, Spring Boot, MongoDB, Bootstrap, Node.js, and RESTful API development. I enjoy designing and developing applications that are not only functional but also user-friendly, responsive, and maintainable.

I have worked on several projects that combine frontend and backend seamlessly, such as CRUD applications, movie review platforms, and mental health web apps. I am also exploring cloud deployment on platforms like Render, Vercel, and Railway, ensuring my applications are production-ready.

I am always eager to learn new technologies, improve my coding skills, and collaborate on meaningful projects. When I'm not coding, I enjoy experimenting with UI/UX design, discovering new tools in the web development ecosystem, and, of course, drinking plenty of coffee ☕ while brainstorming my next project.

I aim to deliver clean, efficient, and maintainable code in every project I work on, and I’m excited to contribute to innovative solutions and real-world applications.
